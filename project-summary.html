実装済み機能

検索機能

  • 英語・カタカナ・ひらがな・スペルミスに対応
  • 複数単語・フレーズ検索（"private investigator"等）
  • カタカナ → 翻訳API → 辞書の3段階変換
  • 「もしかして」候補の表示
  • 英語定義 + 日本語訳の二段表示
  • 検索中のスケルトンローディング表示
  • IME変換中のEnter誤送信防止

単語帳機能

  • 単語の保存・検索回数カウント（x3 のように表示）
  • 配信者タグ（プルダウン選択式・新規追加可能）
  • 配信者ごとのフィルタリング
  • 動画URLメモ機能
  • 単語帳内のテキスト検索
  • ソート（検索回数順・最近調べた順・追加日順）
  • 自分メモ保存（辞書にない単語も自由に保存）

検索の仕組み（処理フロー）

  1. 入力が日本語か判定
  2. 日本語 → wanakana でローマ字に変換
  3. ローマ字で辞書を直接検索（ヒットすれば完了）
  4. 日本語入力なら MyMemory API で英語に翻訳
  5. 翻訳結果で辞書検索（ヒットすれば完了）
  6. ローマ字を「de-japanize」して英語スペルに近づける
    例: purabeito → praveit (b→v), inbesuteigeetaa → investeiget
  7. Datamuse API で音声類似・スペル類似の候補取得
  8. 候補を辞書で引いて最初にヒットしたものを返す
  9. すべての定義を MyMemory API で日本語に翻訳

既知の制限・注意点

  • 翻訳精度 カタカナ→英語変換は完璧ではない（特殊な読みのカタカナ語）
  • 技術用語 fault domain等の専門用語は一般辞書にない → 自分メモで対応
  • データ管理 localStorageなのでブラウザ/端末ごとに別管理（同期なし）
  • API制限 MyMemory翻訳APIは1日の無料リクエスト数に上限あり
